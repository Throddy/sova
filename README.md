# СОВА

Система оперативных выводов и анализа обстановки. Прототип ИИ-помощника для штаба ликвидации ЧС: по донесениям служб он собирает черновик оперативной сводки и у каждого сведения показывает, из какого донесения оно взято.

Сделано к концепции для лаборатории LISA ИТМО и Сибирской пожарно-спасательной академии ГПС МЧС России (учения «Безопасная Арктика-2027»). Автор: Волков Максим, ИТМО.

## Что умеет сейчас

Первый этап: одна ситуация, ландшафтный пожар у посёлка. На входе текстовые донесения, на выходе черновик сводки из трёх частей:

- **обстановка:** последние сведения со временем и номером донесения, например «кромка в 3,6 км от посёлка на 15:30 [Д-7]»;
- **требует внимания:** противоречия, сведения без времени или места, устаревшие сведения и кому задать вопрос;
- **основания:** по каждому сведению исходный текст, цитата, кто передал, когда видели и когда сообщение пришло в штаб.

Решений система не принимает: черновик проверяет офицер.

## Как это работает

1. **Приём:** донесение сохраняется как пришло.
2. **Чтение:** языковая модель находит в тексте сведение и цитату. Это единственный шаг с ИИ.
3. **Память:** сведения хранятся с источником и временем, старые не удаляются.
4. **Проверка:** правила сравнивают сведения и ставят статус: не подтверждено, согласуется, требует уточнения или противоречие.
5. **Черновик:** шаблон собирает сводку.

Шаги 1, 3, 4 и 5 работают. В примерах шаг 2 пока заменён ручной разметкой: запуск локальной модели это следующий этап.

## Запуск

Нужен Python 3.10 или новее. Сторонних библиотек нет, для тестов нужен pytest (`pip install pytest`).

| Команда | Что делает | Что получится |
| --- | --- | --- |
| `python examples/run_example.py` | пример: 11 донесений о пожаре у п. Кедровый, сводка на 16:00 | `examples/kedroviy/OUTPUT.md`, в конце «Совпало 17 из 17» |
| `python -m pytest -q` | тесты | `48 passed` |
| `python run_demo.py` | проверка правил на 90 сгенерированных сценариях, около 15 секунд | `out/results.md` |
| `python experiment/v2/run.py` | пересчёт облачной проверки на текущих правилах | `experiment/v2/RESULTS_RERUN.md` |

**Локальная модель.** Поставить [Ollama](https://ollama.com), один раз скачать модель (`ollama pull qwen3:8b`), запустить `python run_demo.py` (он создаёт тестовые донесения в `data/`), затем `python llm_extract.py --profile fire --model qwen3:8b`. Результат появится в `out/`. Интернет нужен только для скачивания модели.

## Что уже проверено

- **Пример про Кедровый:** сводка совпадает с ожидаемым результатом, записанным до запуска (`examples/kedroviy/EXPECTED.md`), 17 проверок из 17.
- **Облачная проверка:** 8 моих сценариев, модели Sonnet и Haiku, по 3 прогона. СОВА ответила верно на все 20 контрольных вопросов, но сильная модель, которой просто дали все донесения, тоже. Преимущество СОВЫ пока не показано. Подробно: [experiment/v2/RESULTS.md](experiment/v2/RESULTS.md).
- **Сгенерированные сценарии** (пожар, паводок, авария на котельной): критических ошибок на сводку у СОВЫ 0,03, у простых способов («последнее полученное», «голосование источников») 0,56–0,62. Сведения здесь берутся из разметки, поэтому проверяется логика правил, а не модель.

## Ограничения

- Локальная модель ещё не запускалась.
- Все донесения вымышленные. Сроки актуальности и допуски условные, их нужно согласовать с Академией.
- Надёжность источников не учитывается.
